Gemma (local AI via Ollama)

Run Gemma locally for AI-powered homework breakdowns, topic explanations, review drafts, and a chat assistant. Your data never leaves your computer.

Setup: 1. Install Ollama. 2. Pull a model: ollama pull gemma2:2b (small) or ollama pull gemma2:9b (better but heavier). 3. Allow this page through CORS — start Ollama with OLLAMA_ORIGINS="*" ollama serve, or on macOS run launchctl setenv OLLAMA_ORIGINS "*" then restart the Ollama app. 4. Toggle "Enable Gemma features" above, then look for the ✨ buttons throughout the app and the chat bubble in the bottom right.
